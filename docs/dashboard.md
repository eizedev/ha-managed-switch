# Dashboard

The example dashboard shows every port of every switch with link, speed and the connected
device. It finds the switches by itself; nothing to adapt.

1. Settings, Dashboards, *Add dashboard*, *New dashboard from scratch*.
2. Open it, the three dots, *Edit dashboard*, the three dots again, *Raw configuration editor*.
3. Paste [example-dashboard.yaml](assets/example-dashboard.yaml) and save.

![The example dashboard with three switches](assets/screenshots/dashboard.png)

A card that shows a switch like its own web interface (a front panel with coloured ports) is
planned: [roadmap](https://github.com/eizedev/ha-managed-switch/issues?q=is%3Aissue+is%3Aopen+label%3Aroadmap).
