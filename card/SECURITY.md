# Security Policy

## Scope

The card only reads states and the integration's port list in the browser. In scope: anything in
this repository that could run code from device names or other data shown on the card, send
requests that change something, or leak data to another site.

## Reporting a vulnerability

Please report privately via GitHub's
[Report a vulnerability](https://github.com/eizedev/managed-switch-card/security/advisories/new),
not in a public issue. If you cannot use GitHub, email `oss@eize.dev` instead.

## Supported versions

Only the [latest release](https://github.com/eizedev/managed-switch-card/releases/latest)
receives fixes.
